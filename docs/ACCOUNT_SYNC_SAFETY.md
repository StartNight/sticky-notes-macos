# 微软账号切换与凭据边界

## 数据归属

- 每张便笺新增可选 `ownerAccountID`，取自已确认的 Graph `/me.id`，不使用邮箱地址猜账号。
- 新登录在取得 `/me.id` 前不得同步；已保存的新会话身份与令牌存于同一个会话 blob。
- 拉取匹配、上传、删除墓碑、内存删除队列均限定账号；同名 remoteId 不跨账号匹配。
- 每次操作捕获账号和登录代次 UUID。所有 HTTP 请求前、响应后、刷新重试前后检查；退出/重登使旧操作失效。
- 原数据库就地轻量迁移，绝不清库。旧便笺缺归属时全部保留，连同 remoteId/changeKey/webNoteJSON 留在本地隔离，不猜归属、不向新账号发送。重新拉取可能多出一份有归属的云端副本，这是保全旧修改的有意取舍。
- 登录时新建的便笺归当前已确认账号；未登录/身份尚未确认时新建的便笺为纯本地。
- 设置中的确认操作只接纳 `ownerAccountID == nil && remoteId == nil` 的纯本地便笺，不接纳带旧远端链接或其他账号归属的便笺。操作先确认，再同步。
- 列表与便笺窗口提示未关联当前账号的便笺；同一 macOS 用户仍能看到所有本地内容。这是同步隔离，不是本地隐私访问控制。
- 最后同步时间按账号存储。当前实现没有持久化 delta 游标或真实文件夹 ID；不能把以后新增的这类元数据做成全局字段。
- 数据库打不开时停止启动并保留原库，不再删除重建；恢复界面尚未实现。

## 认证与钥匙串

- 直接使用 `ASWebAuthenticationSession`，没有 MSAL，也没有自行启动外部浏览器。系统可能以浏览器 UI 承载该会话。
- 每次交互登录均带 `prompt=select_account`，请求 ephemeral 会话，避免借用已有浏览器 cookies。代价是失去浏览器 SSO/记住账号的便利，可能要求重新输入账号及 MFA；系统浏览器或企业策略是否完全遵从必须实测。
- 显式退出先失效代次、取消 OAuth/身份/刷新任务，清进程状态，再准确删除本应用统一会话及五个已知旧字段的两个后端条目。不触及其他 service、不改 ACL、不删除 token 文件。
- 退出标记保证清理失败时也不会重开自动恢复。HTTP 刷新拒绝只使会话失效，不自动删除用户现有凭据。
- 移除自动读取开发 token 文件的代码，避免退出后重新播种旧账号；文件原件不动。
- 钥匙串读取受锁保护，成功、缺失、拒绝均在进程内记忆。拒绝不再换后端重试并自动覆盖。
- 找到统一会话后不在启动时迁移/重写。只写该会话的单一后端，不再每字段写两份。
- 新登录整包替换令牌，刷新整包更新令牌；刷新及身份查询各 single-flight。旧多字段发现限已知字段、非交互式；需要交互的旧条目不会自动批量弹框，改走明确重新登录。旧条目迁移不自动删除原件。
- 钥匙串保存失败会反馈；显式退出删除失败会提示。不能保证任意签名/ACL 状态下零系统弹窗。

## 安全测量（不记录任何值）

`AUTH_FLOW phase=restore/login/refresh/logout` 为阶段边界。`AUTH_KEYCHAIN` 只记录操作、后端、OSStatus 和累计逻辑读/写/删除次数；`sec=update/add` 补充写入底层调用。不得添加令牌、正文、账号 ID/邮箱、授权完整 URL、请求头或请求体日志。逻辑写一次可能是 Update + Add，不能将调用次数等同于弹窗次数。

GUI 测试人员需记录：阶段、同一二进制 SHA、起止时间（Asia/Shanghai UTC+8）、手工看到的弹窗数、非敏感提示类别、上述计数差值和状态码。不代点允许/始终允许，不扩大 ACL。

1. 新签名包首次启动：独立 macOS 测试用户，先核对目标二进制；登录前后分别计数。
2. 已登录冷启动：退出整个进程后重开同一包，记录 restore 的读取与是否写入；统一会话命中不应自动重写。
3. 点击登录：观察能否输入另一账号/选择账号，记录 token 和 profile 两次逻辑会话保存；不能用浏览器账号列表是否为空判定失败。
4. 刷新：仅测试账号自然过期后触发同步，或经批准的隔离测试工具；不要改用户实际 token/到期字段。记录一次刷新网络请求和一次逻辑写，多个调用应合并。若未出现 AUTH_FLOW refresh，则该阶段未测。
5. 显式退出及重开：只在测试用户的测试凭据上执行，记录 logout 删除状态；重开应保持未登录，不读取开发 token 文件。不能为了验证而退出当前真实会话。
6. A→B→A：各自建立不同的 QA 便笺（需用户另行授权真实 Graph 写入），在 A 有待上传修改/删除/防抖时切 B；B 不收到 A 的正文、remoteId、JSON，A 的墓碑不得删除 B；回 A 才恢复 A 的同步。另测相同 remoteId 的 mock 碰撞、旧无归属便笺、离线本地便笺的显式接纳。

## 证据等级

自动测试使用独立临时 SwiftData 库、内存钥匙串后端和 MockURLProtocol。通过不等于真实微软网页登录、系统钥匙串弹窗或端到端同步通过。正式放行仍需 GUI 和两个测试账号验收；不得因单测通过关闭 P1。
